# 2026-10-17 · v2.3 六项体验修复

用户一次提了 6 个问题，全部自行修完并上线（0.9.0）。

## 1) 收纳空间可调顺序
- 新增 `POST /api/structure/reorder {ent, ids}`（本地 `server/routes/structure.js` + 云端 `entReorder`）。
  校验：同父级、无重复、实体白名单；按数组顺序重写 `sort`（1 基）。
- 新建时可指定插入位置：`POST /zones {name, index}`（本地 `placeAt()`，云端 `insertAtOrder`）。
- 前端 `Studio.js`：新建区域表单加了「排最后 / 插到第 N 位」下拉；区域、柜子、层、箱都有 ▲▼
  （`moveZone/moveCabinet/moveShelf/moveBox`，走 `window.TidyShared.moveInOrder`）。
- 柜子在树里按楼层分组显示，所以提交前按「楼层升序 + 层内顺序」摊平，保证视觉顺序可预期。

## 2) 识别模块：手动录入 + 数量双击
- 新增第三种模式「✍️ 手动录入」：上传照片后自己填名称/类别/数量/位置，完全不调 AI。
- 新接口 `POST /intake/manual`（本地 multer、云端直传存储），只占一条 `status='done'` 的队列记录，
  不污染「待确认」队列；`/intake/confirm` 对 `payload.manual` 放开 index 限制。
- 数量：`双击数字 → 变输入框`（`startEditQty/commitQty`，Enter/Esc/blur 提交），CSS `.qty-num/.qty-input`。

## 3) 默认空间
- `localStorage['tidy-space-default:<uid>']` + `window.__tidySetDefaultSpace()`。
- 启动优先级：邀请码 > 默认空间 > 上次所在空间 > 个人空间；默认实验室若已不存在/被移出则自动清除。
- 入口：顶栏空间面板 + 实验室页各一个「设为默认 / 取消默认」。

## 4) 总览完整 + 图片不再丢
- 根因一：`shelfView()` 写死 `items.slice(0, 8)` → 一层超过 8 件永远看不到。本地/云端两处都去掉截断。
- 根因二：前端 `shownItems` 只给 4 个且默认折叠。改为**默认全部展开**（`collapsed: []`），
  超过 4 件才出现「收起」，展开时返回全部。
- 根因三：主图子查询写死 `is_main=1`，历史数据里全是 0 时直接空。全部改成
  `ORDER BY ii.is_main DESC, ii.id ASC LIMIT 1`（lib.js / items / search / stats 共 5 处）。
- 根因四：云端 `imgSrc` 签不出 URL 时返回空字符串（图消失），且 `resolveImages` 每次失败都触发
  `dataVersion++` → 「刷新→再签→再刷新」死循环（手机发烫的另一半原因）。
  现在：签不出来先给占位图 + 后台补签；失败 key 进 5 分钟冷却；只有 URL 真变化才刷新。
- `item_images` 读取不再按 `lab_id` 过滤（图片是附属行，lab_id 不一致会让整批图消失），RLS 仍兜底。

## 5) 搜索
- 根因：类别下拉传的是**类别名**，后端拿它跟 `category_id` 比数字 → 选类别必零结果。
- 新增双端共用打分 `TidyShared.matchItems/scoreItem`：整名 120 / 前缀 100 / 包含 80 / 别名 75/60 /
  类别 40 / 备注 25 / 保序子序列 18；多词为「且」关系；同分按库存与 id 兜底。
- `categoryMatches` 同时接受 id 与名称。本地 `server/routes/search.js` 与云端 `search()` 共用同一函数。

## 6) 手机发烫 / 卡顿
- 顶栏时钟：窄屏 15 秒一跳（原来 1 秒），切后台停表（`visibilitychange`）。
- 宠物：`(pointer:coarse)` 下关闭常驻浮动/阴影呼吸，并**不注册视线追踪 rAF**（滚动会不停触发 pointermove）。
- 玻璃拟态：窄屏/触屏 `backdrop-filter` 从 26px 降到 10px，去掉 `::before` 渐变层，取消 hover 位移。
- `body.page-hidden` 时暂停全部 CSS 动画；`prefers-reduced-motion` 直接关装饰动画。
- 列表图片统一 `loading="lazy" decoding="async"`；`loadContext()` 并发去重（同刻多组件只拉一次 8 张表）。
