## v2.5 手机发热「治本」（118/118 测试通过）

先用 CDP + Edge headless 在 390×844 / DPR3 / CPU 4x 降速 下量化，再按数据改代码。
**实测基线**：图片解码内存 781MB（98 张 1706×1279 原图，屏上只显示 17px）、滚动 44.6fps、滚动期样式重算 35 次/秒、宠物 3 个无限动画常驻、空闲主线程 10%。

四个真因 + 修法：

1. **原图直出（最大项）** → 新增 `server/thumb.js`：`GET /images/**?w=96|160|320|640|1280` 用 sharp 生成 webp（带磁盘缓存 + 单飞去重 + mtime 校验 + 失败回退原图），`app.use('/images', serveThumb, static)`；上传即 `warm()` 预热，用户浏览零等待。前端 `imgSrc(key, w)` 第二参数：本地拼 `?w=`，云端走 `/render/image/sign/` 变换并在 4xx 时全局降级一次（`imgTransformOK`）。
   → 解码内存 **781MB → 17MB**，96px 缩略图 1.1KB、160px 2.6KB。
2. **背景光斑 `.blob`**（3 个 fixed + blur(110px) 大图层，滚动每帧重新合成）→ 对照实验确认它是唯一影响滚动的因素（隐藏后 44.6 → 60.4fps）；perf-lite 下 `display:none`，改由 body 的静态 radial-gradient 保留观感。噪点 `::after` 同时移除。
3. **宠物常驻动画**（`.zzz` 3 个 infinite + 待机浮动）→ `autoPlayOn()` 手机默认 false（按需表演，点它才动），桌面保持；`.zzz` 只有睡着时才挂动画；lite 下间隔 18~40s 且只挑短动作。
4. **图片补签触发全量重拉** → 已在上版改为 `store.imgVersion`。

**最终实测**（静置 15s）：主线程 0.5%、脚本 0.0%、样式重算 0.07 次/秒、运行中动画 0 个。滚动 60.2fps 无常帧、样式重算 0.22 次/秒（原 35）。

其他：`server/routes/backup.js` 恢复备份时一并清 `data/thumbs`（缩略图是派生缓存，缓存判断只看 mtime，不清会出现「照片对不上物品」）；列表缩略图 64px 在 3x 屏需要 192px，SearchPage/StatsPage 从 96 提到 160。
测试：`test/m13.mobile-perf.test.js`（9 个用例：缩略图生成/缓存/白名单/404、全量 imgSrc 必须带尺寸、光斑移除、宠物降级、预热）。
测量脚本：%TEMP%/tidy-idle.js（静置功耗）、tidy-probe2.js（首屏/空闲/滚动）、tidy-scroll-exp.js（逐层对照）。

## v2.7 修「切模块长时间刷不出来」（135/135 测试通过）

实测（4G 模拟：180ms 延迟 / 2Mbps / CPU 4x）：本地服务每个接口 <20ms，所以不是后端慢，而是**切换时的等待没有任何反馈 + 每次都重拉一遍数据**。

四类原因与修法：
1. **数据没到 = 整页空白**（各页正文全靠 `v-if="ov/b/cfg/loaded"`）→ 新增 `PageSkeleton` 组件（`page-skeleton`），Dashboard/Studio/Stats/Settings 数据未到先画版式；骨架超 8 秒显示「网络有点慢 + 重新加载」，避免永远转圈。
2. **每次切模块都重新请求**` → `api.js` 加 GET 缓存（默认 15s；`/stats/meta`、`/structure`、`/settings`、`/system/info` 30~60s）+ 并发合并（同路径共用 Promise）+ **写操作全清缓存** + 缓存 key 带空间标识 + 命中返回 `structuredClone` 副本（防两个页面互相改）+ 上限 60 条。
3. **串行请求**：Settings 三个 GET 改 `Promise.all`（3 RTT → 1）；ItemDetail 详情与类别表并行，并在数据到达前显示遮罩+加载态（原来点物品 200~800ms 毫无反应）。
4. **云端上下文重复加载**：`loadContextFresh` 一次拉 8 张表，切一次模块可能触发两三次 → 加 2.5s「读快照」`readCtx()`，写操作 `invalidateReadCtx()`，且快照带 `spaceSig()`（跨空间不复用；m10.3 就是靠这条修的）。

另加：顶栏细进度条 `store.pending`（>160ms 才出现，本地不闪）；Studio/Settings 加载失败不再卡在骨架屏，显示错误 + 重试。

实测（4G 模拟）：冷切换有反馈 68~151ms、数据 491~577ms；15s 内二次进入 76~117ms 且 **0 个 API 请求**。
测试：`test/m15.navigation.test.js`（11 个用例，前 6 个用 vm 沙箱跑真实 `api.js` 验证缓存/合并/失效/空间隔离，不是纯文本断言）。
