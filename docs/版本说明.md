## 四、版本号说明

| 项 | 说明 |
|---|---|
| **网页版** | `package.json` 的 `version` 为 **0.7.0**，服务接口 `GET /api/system/info` 同样返回 `version: "0.7.0"`。历史上提交信息里标注的 `v1.2`~`v1.7` 是按迭代次数标记的功能里程碑，与该字段并非同一套编号；**以 0.7.0 为当前基线**。 |
| **桌面版 js-pet** | 独立编号，当前 **0.1.0**；安装包文件名中的版本号即取自此字段。 |
| **PRD 文档** | `PRD.md` 内部的 v1.0 / v2.0 指**需求文档版本**（v2.0 为「网站上线 + 桌面安装包」阶段的增补需求），不是软件版本号。 |

## 五、本仓库的分区整理规则

本仓库从原始工程整理而来，按「**两个产品 + 文档 + 设计稿**」分区：

```
tidy-up(2)/
├── server/ public/ test/     ← 产品一：网页版 TidyLab 源码
├── docs/                     ← 网页版文档（PRD / 需求 / 计划 / 测试报告）与设计稿
│   └── design/               ← 设计效果图、宠物原型页
└── desktop/                  ← 产品二：桌面版 js-pet 源码（含其独立 README 与 docs）
```

### 纳入仓库的内容

- 全部源码、建表脚本、配置模板、测试用例；
- 构建配置（`package.json` / `electron-builder.yml`）与构建工具脚本；
- 运行所需成品素材：`public/pet-assets/`（宠物形象，约 215 KB）、`desktop/build/`（应用图标）、`desktop/src/renderer/pet/looks/`（内置形象）；
- 全套文档与设计/原型稿。

### 主动排除的内容

| 排除项 | 原因 |
|---|---|
| `node_modules/` | 依赖，`npm install` 可重建 |
| `data/`、`backups/` | 本机运行时数据；且 `data/config.json` **含真实 API Key，严禁提交** |
| `dist/`、`desktop/dist/` | 构建产物（`desktop/dist` 达数百 MB），可重新构建 |
| `.workbuddy/`、`*.genie` | 本机开发工具产物，与项目无关 |
| `*.log`、`.DS_Store` 等 | 日志与系统杂项 |
| `pet-assets/*.png`（约 10 MB）、`desktop/src/assets/builtin-looks/raw{2}/`（约 14 MB） | AI 生成的**美术中间素材**，运行时不需要（打包配置已显式排除），为保证仓库轻量未纳入 |

> 上述排除项均已在 `.gitignore` 中声明；美术源文件在原工程中完整保留，如需二次加工可另行取用。
