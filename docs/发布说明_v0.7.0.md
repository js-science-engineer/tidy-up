# TidyLab 网页版 v0.7.0 发布说明

> 首个上线版本 · 2026-10-05
> 拍一张照片 → AI 认出是什么 → 建议放哪个柜子哪一格 → 一键入库 → 随时搜索、随时查看每个柜子里有什么。

## ✨ 本版亮点

- 🌐 **正式上线**：公网可访问，HTTPS 加密，打开即用。
- 👥 **多用户体系**：邮箱注册登录，账号之间数据**完全隔离**（数据库行级安全策略强制保证），换账号看不到彼此的任何物品与图片。
- ☁️ **云端数据**：物品、结构、流水、图片都存在云端，换设备、换浏览器数据都在。
- 📸 **识别入库**：AI 识别 + 联网匹配标准名称与实物图 + 「区域 › 柜 › 层 › 箱」分区建议（带理由）。
- 🗄️ **收纳空间**：一句话生成四级柜体结构；拖拽编辑；2D 可视化下钻；柜子可传实拍照片对照。
- 🔍 **搜索**：精确匹配 + AI 语义搜索（「那个蓝色的测电压的东西」也能找到万用表）。
- 📦 **出库与流水**：数量扣减、归零标记「已取空」、历史全程可追溯。
- 📊 **统计看板**：物品 / 区域 / 柜体总览与出入库明细。
- 🐾 **电子宠物**：打开网站自动蹦出的桌宠，12 态交互、拖拽、换装，形象按账号隔离。
- 💾 **数据安全**：本地模式保留一键备份 / 恢复；核心数据实时落盘。

## 📥 使用方式

| 方式 | 地址 / 操作 | 说明 |
|---|---|---|
| **在线使用**（推荐） | <https://tidylab.app.workbuddy.host/> | 云端多用户，邮箱注册（需验证码）后即可使用 |
| **本地运行** | 下载源码 → `npm install` → `npm start` | 单机使用、数据存本机，无需注册；详见 [安装指南](安装指南.md) |

> 两种模式共用同一套前端代码：程序启动时自动探测运行环境并切换，本地数据与线上数据互不干扰。

## 🔒 数据与隐私

- **账号隔离**：每张业务表都带用户归属字段并启用行级安全策略，任何账号都无法读取或修改他人数据。
- **AI Key 安全**：大模型 Key 由服务端保管，**永不下发到前端**；本地模式的 Key 存在 `data/config.json`（已被 `.gitignore` 排除，不会误提交）。
- **图片**：云端模式存云端对象存储；本地模式存 `data/images/`。

## ⚠️ 已知问题

- 平台级**邮箱验证码**为注册必需步骤，若未收到请检查垃圾邮件或稍后重试。
- 移动端布局仍在适配中，当前按桌面宽度设计（手机浏览器可正常上传照片，页面排版暂未针对小屏优化）。
- 云端模式暂**不提供**导入 / 导出与备份恢复（该能力目前为本地模式专属），后续版本补齐。

## 🛠 技术参数

| 项 | 说明 |
|---|---|
| 前端 | Vue 3（CDN 引入）+ 原生 JS，无打包器 |
| 后端 | Node.js ≥ 22.13 + Express 4（本地模式） |
| 数据 | 本地 SQLite（`better-sqlite3` 优先 / `node:sqlite` 兜底）／ 云端托管数据库 + RLS |
| AI | 智谱 GLM-4V-Flash（免费）／ 阿里云百炼 Qwen-VL，OpenAI 兼容协议，可切换 |
| 测试 | 66 项自动化测试（M1~M8）全部通过 |
