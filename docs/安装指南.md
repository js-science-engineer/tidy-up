## 一、网页版 · 本地安装

### 1.1 环境要求

| 项 | 要求 |
|---|---|
| Node.js | **≥ 22.13**（推荐 22 LTS）。低于此版本内置 `node:sqlite` 需 `--experimental-sqlite` 标志，程序将无法启动 |
| 操作系统 | Windows 10+ / macOS 12+ / Linux |
| 磁盘 | 约 200 MB（依赖 + 数据） |
| 浏览器 | Chrome / Edge / Firefox / Safari 等现代浏览器 |

### 1.2 安装 Node.js

**Windows**

- 方式一（推荐）：到 <https://nodejs.org/> 下载 **LTS** 版本安装包，双击下一步即可。
- 方式二（命令行）：`winget install OpenJS.NodeJS.LTS`

**macOS**

- 到 <https://nodejs.org/> 下载 `.pkg` 安装；或使用 Homebrew：`brew install node@22`

**验证安装**（打开终端 / CMD）：

```bash
node -v     # 应输出 v22.x 或更高
npm -v
```

> 若 `node -v` 低于 22.13，服务会启动失败（内置 `node:sqlite` 需要 `--experimental-sqlite` 标志），请升级到 22.13 或更高。

### 1.3 获取代码

```bash
git clone <你的仓库地址> tidy-up
cd tidy-up
```

或直接在 GitHub 页面点 **Code → Download ZIP**，解压后进入目录。

### 1.4 安装依赖

```bash
npm install
```

> 国内网络较慢时，可切换镜像后重试：
> ```bash
> npm config set registry https://registry.npmmirror.com
> npm install
> ```

### 1.5 启动

```bash
npm start
```

或一键脚本：

- **Windows**：双击 `start.bat`（会自动安装依赖、启动服务并打开浏览器）
- **macOS / Linux**：`chmod +x start.sh && ./start.sh`

启动成功后终端会打印访问地址，浏览器会自动打开 **http://localhost:5175**。

**自定义端口**：设置环境变量 `PORT` 后启动，例如 Windows `set PORT=8080 && npm start`，macOS/Linux `PORT=8080 npm start`。

### 1.6 手机拍照上传

1. 手机与电脑连接**同一个 WiFi**；
2. 服务启动时终端会打印局域网地址（形如 `http://192.168.1.20:5175`），用手机浏览器打开该地址；
3. 进入「识别入库」即可拍照或选图上传。

> 打不开时，多为 **Windows 防火墙**拦截：在弹窗中勾选「专用网络」允许访问，或到「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」中放行 Node.js。

## 二、配置 AI 识别能力

识别、语义搜索、分区建议依赖云端大模型。**不需要写代码，在「设置」页填 Key 即生效。**

### 2.1 推荐：智谱 GLM-4V-Flash（免费）

1. 打开 <https://open.bigmodel.cn/> 注册并登录；
2. 进入「API Keys」创建一个密钥（形如 `xxxxxxxx.xxxxxxxx`）；
3. 回到 TidyLab「**设置**」页 → 供应商选 **智谱 GLM** → 粘贴 Key → 保存。

默认模型 `glm-4v-flash` 目前免费，足够个人日常使用。

### 2.2 备选：阿里云百炼 Qwen-VL

1. 打开 <https://bailian.console.aliyun.com/> 开通服务并获取 API Key；
2. 「设置」页 → 供应商选 **通义千问 Qwen-VL** → 填 Key → 保存。

### 2.3 说明

- Key 保存在本机 `data/config.json`，**只在后端使用，永不下发到前端**；界面中以打码形式显示。
- 未填 Key 时，识别/语义搜索会返回明确的「未配置 API Key」提示，界面不会崩溃；填好后无需重启，立即生效。
- Key 属于敏感信息，`data/` 目录已被 `.gitignore` 排除，请勿手动提交。

## 三、网页版 · 云端部署

云端版本用于「公网访问 + 多用户」，由 **WorkBuddy 云服务托管**提供：云数据库（PostgreSQL + 行级安全 RLS）、云文件存储、邮箱注册登录、免费大模型调用。**无需自购服务器、免运维。**

### 3.1 架构要点

- 云端模式下，**前端通过云端 SDK 直连**数据库与存储，身份来自浏览器端登录会话，所有私有表由 **RLS** 按 `owner_id` 隔离，账号之间互不可见；
- 后端 `server/` 仍负责 **AI 识别**（服务端保管 Key）与少量设置代理；
- 前端通过 `public/js/cloud/boot.js` 探测 `GET /api/system/info` 的 `cloud` 字段自动切换本地 / 云端模式，**同一套前端代码两种模式通用**。

### 3.2 部署步骤概览

1. 在托管平台创建项目，建好 10 张业务表、`owner_id` 默认 `auth.uid()` 与对应 RLS 策略、索引，并写入 11 个预设分类；
2. 生成 `server/cloud-config.json`（含 `endpoint` 与 `publishableKey`；`publishableKey` 无权限含义，可随应用分发）；
3. 以 `TIDY_CLOUD=1` 环境变量启动服务，前端即进入云端模式；
4. 部署到托管平台（本项目线上地址：<https://tidylab.app.workbuddy.host/>）。

> 详细设计与验收标准见 [PRD.md](PRD.md) 第二部分（§12~§17）。

### 3.3 本地 / 云端共存

本地 `start.bat`、SQLite 模式与本地数据**完全保留**，两种模式互不干扰；线上从空库开始，本地数据不做迁移（PRD 已确认的决策）。

## 四、桌面版 js-pet 安装

桌面版是**独立的 Electron 应用**（常驻桌面的电子宠物），源码位于本仓库 `desktop/`。

### 4.1 使用发布版安装包

从 Releases 下载对应文件：

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows | `js-pet-0.1.0-setup.exe` | **安装版**（推荐）：双击安装，可选择安装目录，含桌面/开始菜单快捷方式，可卸载 |
| Windows | `js-pet-0.1.0-portable.exe` | **便携版**：单文件双击即用，不写注册表 |
| macOS | `js-pet-0.1.0-arm64.dmg` / `-x64.dmg` | 未签名版本 |

**Windows 安装步骤**

1. 双击 `js-pet-0.1.0-setup.exe`；
2. 按向导选择安装目录 → 完成；
3. 桌面与开始菜单出现 `js-pet` 快捷方式（图标为宠物形象），双击启动；
4. 宠物出现在桌面右下角，点击它打开面板可进入「养成 / 形象 / 设置」三页签。

> 若 Windows SmartScreen 提示「未知发布者」，点「更多信息 → 仍要运行」即可（当前版本未做代码签名）。

**macOS 说明**

未签名应用首次打开会被 Gatekeeper 拦截：

1. 将 `.dmg` 拖入「应用程序」；
2. **右键点击应用 → 打开** → 在弹窗中点「打开」；
3. 之后即可正常双击启动。

更详细步骤见 [`desktop/docs/install-macos.md`](../desktop/docs/install-macos.md)。若需自行构建 mac 包，见 [`desktop/docs/BUILD_MAC.md`](../desktop/docs/BUILD_MAC.md)（须在 macOS 机器上执行 `npm run build:mac`）。

### 4.2 从源码运行 / 构建

```bash
cd desktop
npm install
npm start          # 开发运行
npm test           # 单元测试（117 项）
npm run smoke      # Electron 冒烟自检
npm run build:win  # 打 Windows 安装包 + 便携版（产物在 desktop/dist/）
```

> Windows 打包若下载 Electron 超时，先设置镜像：
> ```bash
> set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
> npm run build:win
> ```

### 4.3 数据与卸载

- 数据位置：Windows `%APPDATA%/js-pet`，macOS `~/Library/Application Support/js-pet`；
- **卸载不会删除用户数据**（养成进度、形象、设置均保留）；彻底清除请手动删除上述目录；
- 设置页可一键**导出全部数据为 JSON**，便于换机迁移。

## 五、常见问题 FAQ

**Q1：启动时报端口被占用（EADDRINUSE）**
换端口启动：`PORT=8090 npm start`（Windows CMD：`set PORT=8090 && npm start`）；或关闭占用 5175 端口的程序。

**Q2：`npm install` 很慢或失败**
切换镜像：`npm config set registry https://registry.npmmirror.com`，再执行 `npm install`。

**Q3：识别时报「未配置 API Key」或「请求失败」**
先到「设置」页确认 Key 已填写并保存；检查网络是否能访问对应大模型服务；填错 Key 或断网时界面会给出明确提示，恢复后重试即可，不会产生脏数据。

**Q4：上传照片不识别 / 提示不支持的格式**
支持 `jpg / png / webp / gif / bmp / avif`，单张 ≤ 10 MB。**HEIC（iPhone 默认格式）请先转成 JPG** 再上传。

**Q5：手机打不开局域网地址**
确认手机与电脑在同一 WiFi；放行 Windows 防火墙对 Node.js 的「专用网络」访问；部分路由器开启了「AP 隔离」，需在路由器设置中关闭。

**Q6：我的数据在哪？怎么备份？**
本地模式：`data/`（`tidy.db` + 图片）与 `backups/`（zip 备份）。可在「设置」页一键备份；服务每天首次启动会自动静默备份一次（保留最近 10 份）。恢复时选备份 zip → 二次确认 → 系统会先做一次当前数据的应急备份再覆盖。

**Q7：想要更好的数据库性能**
默认用 Node 内置的 `node:sqlite`。可选安装原生驱动：
```bash
npm install better-sqlite3
```
程序会自动优先使用它（需本机具备编译环境）。

**Q8：怎么跑测试确认安装正常？**
```bash
npm test                 # 网页版，应全部通过
cd desktop && npm test   # 桌面版
```

**Q9：宠物显示很慢 / 图片显示不全？**
仓库内素材已做量化压缩（`public/pet-assets/` 共约 215 KB）并在页面预载，正常不会卡。若自行替换了高清素材导致变慢，建议压缩后再放入。

**Q10：我不想用 AI 功能，能离线用吗？**
可以。收纳空间编辑、搜索（精确）、出库、统计、备份等核心功能均不依赖网络；仅「AI 识别 / 语义搜索 / 一句话生成柜体」需要 Key 与网络。
