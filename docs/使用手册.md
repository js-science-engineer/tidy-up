## 一、界面总览

```
┌─────────────────────────────────────────────────────────┐
│ 顶栏（液态玻璃）：品牌 Logo · 全局搜索框 · 当地时间 · 主题切换 │
├────┬────────────────────────────────────────────────────┤
│ 左 │                                                    │
│ 侧 │              主内容区（卡片流）                      │
│ 导 │   总览 / 收纳空间 / 识别入库 / 搜索 / 统计看板 / 设置  │
│ 航 │                                                    │
└────┴────────────────────────────────────────────────────┘
```

**六个模块**（左侧竖向图标导航）：

| 图标 | 模块 | 做什么 |
|---|---|---|
| 🏠 | 总览 | 全局仪表盘：统计卡、空间总览、今日计划、最近入库 |
| 🗄️ | 收纳空间 | 数字化的柜体结构：生成、编辑、2D 查看、拖拽移位 |
| 📸 | 识别入库 | 拍/传照片 → AI 识别 → 分区建议 → 确认入库 |
| 🔍 | 搜索 | 精确搜索 + AI 语义搜索（模糊描述也能找到） |
| 📊 | 统计看板 | 物品/区域/柜体总览与出入库明细 |
| ⚙️ | 设置 | AI Key、主题、备份/恢复、模块顺序 |

**自定义模块顺序**：点左侧导航底部的 **⇅** 图标 → 拖动整行或点 ▲▼ 调整 →「排第一位的就是打开网站时的首页」。改完点「完成」自动保存。

## 二、四步上手

1. **建结构** — 进「🗄️ 收纳空间」，用一句自然语言描述你的柜子，让 AI 生成四级结构（区域 › 柜 › 层/抽屉 › 箱子）。
   例：`两层。第一层 5 个柜子：1 个双开门 + 4 个单开门。第二层 3 个柜子，都是双开门。`
2. **填 Key** — 进「⚙️ 设置」填 AI Key（推荐智谱 GLM-4V-Flash，免费），保存即生效。
3. **录物品** — 进「📸 识别入库」上传照片，确认 AI 识别的名称/类别/数量，采纳分区建议，点「确认入库」。
4. **找东西** — 进「🔍 搜索」，输入「STM32」或「那个蓝色的测电压的东西」，点结果查看详情与位置。

## 三、模块详解

### 3.1 🏠 总览

自上而下：

| 区块 | 说明 | 可点击 |
|---|---|---|
| 欢迎语 + 摘要 | 问候语 +「今天已入库 N 件」一句话动态 | — |
| 统计卡 ×4 | 物品总数 / 区域数 / 柜子数 / 今日入库数 | 跳到对应模块 |
| 空间总览 | 每个区域一张卡，含各柜子缩略图（实色=满、半透明=部分、描边=空） | 点柜子 → 进收纳空间并定位该柜 |
| 今日计划 | 今日待确认队列 + 今日入库记录 + 今日取出记录 | 点条目 → 跳对应位置 |
| 最近入库 | 最近入库物品卡（缩略图 + 名称 + 位置路径） | 点 → 物品详情 |

> **整柜拖拽移位**：在总览中可把一件物品拖到另一个柜子上，系统会**自动挑选最空的一层**放入，全程有视觉反馈，且全站数据同步更新。

### 3.2 🗄️ 收纳空间

**① AI 对话生成结构**

在对话框用中文描述你的柜体，AI 会生成结构并**自动编号**（区域一 / 区域二…）。生成前可预览、可重新描述、可撤销上一步。

**② 手动编辑**

- 添加 / 删除 / 重命名：区域、柜子、层 / 抽屉、箱子
- 调整**门型**：双开门 / 单开门 / 抽屉
- 调整顺序；支持**撤销最近一次编辑**

**③ 2D 可视化浏览**

逐级下钻：区域 → 柜 → 层 → 箱。柜内显示箱子标签与**占用率条**，一眼看出哪层快满了。

**④ 柜子实拍照片**

给柜子/层级上传一张真实照片，作为「这个柜子长什么样」的对照。该照片会**贯通到识别入库**环节，选位置时能对照实拍图确认，避免放错。

**⑤ 物品相册与移位**

- 在同一柜内或跨柜拖拽物品，即可改变存放位置；
- 物品相册可查看同一物品在每个位置的照片与数量。

### 3.3 📸 识别入库

#### 上传方式

- **电脑**：点击选择文件，或把图片直接**拖拽**到上传区；
- **手机**：手机与电脑连同一 WiFi，用手机浏览器打开局域网地址后拍照/选图（见 [安装指南 §1.6](安装指南.md#16-手机拍照上传)）。

#### 两种识别模式

| 模式 | 适用 | 行为 |
|---|---|---|
| **一图一物** | 拍单件物品 | 一张图识别一个物品 |
| **整层批量** | 拍一整个抽屉/一层 | 识别出多个物品，逐个确认，可删除误识别项 |

#### 识别 → 入库流程

1. **上传照片** → AI 返回：名称、类别（落在预设分类内）、置信度、候选名称（≥2 个）。
2. **编辑结果**：名称（可从候选中选，也可任意改）、类别（预设类中选）、数量（步进器）。
3. **联网匹配实物图**：展示候选实物图，点选采用；**不点选直接确认则自动采用贴合度最高的一组**。
4. **采纳分区建议**：系统给出「区域 › 柜 › 层 › 箱」推荐路径 + 一句理由；你也可以改选任意位置。若该柜有实拍照片，会一并展示供对照。
5. **确认入库** → 写库存 + 写流水 + 柜体视图即时更新。

> 支持格式：`jpg / png / webp / gif / bmp / avif`，单张 ≤ 10 MB。**HEIC 请先转 JPG**。
> 识别失败 / 断网 / 未填 Key 时会给出明确提示，可重试，不会产生脏数据。

#### 多位置独立数量

同一件物品可以同时放在多个位置，**每个位置各记各的数量**，互不干扰。例如万用表 A 柜放 2 个、B 柜放 1 个，搜索时总数量自动合计为 3。

### 3.4 📦 出库（取出）

1. 通过搜索或浏览定位物品；
2. 打开物品详情 → 选「取出」；
3. 填数量（可全部或部分）→ 确认 → 数量扣减并写入流水；
4. **扣到 0 会标记「已取空」**——位置与历史记录仍保留，物品不会消失，方便日后查证。

### 3.5 🔍 搜索

| 方式 | 说明 |
|---|---|
| **精确匹配** | 按名称 / 别名关键词过滤，如「STM32」 |
| **语义搜索** | 用模糊描述，AI 推测可能物品并按匹配度排序，如「那个蓝色的测电压的东西」→ 万用表 |
| **筛选** | 按类别、区域过滤 |
| **结果行** | 缩略图 + 名称 + 位置路径 + 数量 + 匹配度，点击打开详情 |

### 3.6 📊 统计看板

- 物品 / 区域 / 柜体总量总览；
- 出入库明细流水（时间、物品、动作、数量、位置）；
- 存储占用情况，快速定位「空柜」与「满柜」。

### 3.7 ⚙️ 设置

| 项 | 说明 |
|---|---|
| AI 供应商 | 智谱 GLM / 通义千问 Qwen-VL 切换，填 Key（打码显示，永不下发前端） |
| 主题 | 深色（默认）/ 浅色一键切换 |
| 备份 / 恢复 | 一键备份为 zip；选备份恢复（二次确认，恢复前自动应急备份） |
| 模块顺序 | 与左侧导航 ⇅ 等价 |
| 端口等 | 仅本地模式显示；云端模式隐藏本地专属项 |

## 四、电子宠物怎么玩

打开网站后，电子宠物会**自动蹦出**在页面上，可自由拖拽到任意位置。

| 交互 | 效果 |
|---|---|
| 单击 | 抚摸，涨亲密度 |
| 双击 | 嬉戏 |
| 按住拖动 | 把宠物拖到喜欢的位置（自动限制在可视区域内，不会跑出屏幕） |
| 右键 | 打开菜单（喂食、改名、换装、隐藏等） |
| 鼠标移动 | 宠物的视线会跟着鼠标走 |
| 空闲 | 自己溜达、打盹、说话气泡 |

- **养成**：会饿、会无聊；喂食 / 抚摸 / 玩耍提升亲密度，满 30 升一级；
- **换装**：上传一张宠物图片自动抠图换装（绿幕或纯白底效果最稳）；
- **多账号隔离**（云端模式）：自定义形象按账号保存，换账号不会串。

## 五、数据与备份

- 所有写操作**实时落盘**（SQLite 事务），刷新、关浏览器、重启电脑都不丢；
- **一键备份**：设置页点击即可，生成 `backups/backup-YYYYMMDD-HHmmss.zip`；
- **自动备份**：每天首次启动若当天尚无备份，会静默自动备份一次（保留最近 10 份）；
- **恢复**：选择备份 zip → 二次确认 → 系统先做一次当前数据的应急备份 → 覆盖恢复 → 刷新界面；
- 图片与数据库**同时备份、同时还原**，保证一致性。

> 云端模式的数据安全由托管平台负责，本地备份/恢复为本地模式专属功能。

## 六、多用户（云端模式）

线上站点采用邮箱注册登录，账号之间数据**完全隔离**：

- 注册：邮箱 + 密码（需邮箱验证码），登录后进入自己的空库首页；
- 任意账号**无法读取或修改**他人数据（由数据库行级安全策略强制保证）；
- 电子宠物自定义形象同样按账号隔离；
- 登出后会话失效，重新登录恢复正常。

本地模式无需登录，直接使用。

## 七、技巧与小贴士

1. **把常用模块排第一**：比如你主要是录入，就把「识别入库」拖到第一位，打开网站直接进录入页。
2. **一次拍一层**：整理抽屉时用「整层批量」，一次录完一层，比一件件拍快得多。
3. **先建结构再录物品**：有柜体结构后，分区建议才有意义（否则没有可推荐的位置）。
4. **善用柜子实拍图**：给每个柜子传一张实拍照片，入库选位置时能对照，减少放错。
5. **改名随时可改**：AI 认错名字不要紧，入库前后都能改，别名也会一起用于搜索。
6. **扣到 0 不等于删除**：取空只是数量归零，历史与位置都在，查「这东西以前放过哪」很有用。
7. **别删 `data/` 目录**：本地模式下它就是你的全部数据，删了等于清库（有备份可恢复）。
