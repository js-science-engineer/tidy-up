## 真机人工复检清单（发布前建议过一遍）

2. 托盘：左键显隐、右键菜单弹出位置、勾选态
3. 上传一张白底/绿幕宠物图换装，确认抠图效果
4. 断网重启，确认数据完好、无任何联网请求
5. macOS 机器执行 `npm run build:mac` 出 dmg 并按指引放行验证
6. M8-5 压力项：连续互动 100 次；M8-6：拔外接屏/改系统时间跨天/强杀 20 次
