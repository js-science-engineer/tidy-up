# js-pet v0.1.0 发布说明

> 首个公开版本 · 2026-10-05
> js-pet 是一只常驻桌面的电子宠物：养成、互动、散步，数据只保存在你自己的电脑上。

## ✨ 功能

- **桌面常驻**：透明无边框窗口、置顶显示、不占任务栏、不挡操作（只有宠物本体接收鼠标）
- **轻度养成**：饱食度/心情会随时间下降，抚摸/喂食/玩耍恢复并涨亲密度，亲密度满 30 升一级（最高 Lv.99）
- **互动**：单击抚摸、双击嬉戏、按住拖动换位置、右键菜单、说话气泡、视线追踪
- **动作**：招手、兴奋、跳舞、跳跃、散步、张望、转身（4 面 3D 转身）、打盹等 11 组动画
- **形象系统**：内置原创形象"经典小圆"；支持上传自己的图片自动抠图换装、删除、切换
- **桌面散步**：开启后宠物会在桌面上自己溜达（可在菜单/设置随时关）
- **面板**：养成数值可视化、形象管理、大小调节（100~260px）
- **开机自启**（可选，默认关）
- **数据安全**：本地 JSON 存储、原子写入、损坏自动从备份恢复（保留最近 5 份）、24h 自动备份、一键导出/恢复
- **系统托盘**：左键显隐，右键全套菜单

## 🔒 隐私

- 不联网：全程无任何网络请求（可断网使用）
- 不采集：数据只存在本机
  - Windows：`C:\Users\你\AppData\Roaming\js-pet\`
  - macOS：`~/Library/Application Support/js-pet/`
- 卸载不删数据（Windows 安装版默认保留，可自行删除上述目录）

## ⚠️ 已知问题

- 部分无独立显卡的机器首次启动可能有 1~2 秒白屏延迟
- Windows 上如果任务栏图标偶尔不刷新，重启应用即可
- 极少数杀毒软件可能误报便携版，添加信任即可（安装版无此问题）
