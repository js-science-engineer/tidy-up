# js-pet macOS 安装指引（未签名版）

> js-pet 目前采用"精简上线"策略：macOS 安装包未做签名与公证（签名需要 Apple 开发者账号，$99/年）。
> 因此首次打开会被 macOS Gatekeeper 拦截，**这是正常现象，按下面任一方法放行即可**。

## 方法一：右键打开（推荐，最简单）

1. 下载 `js-pet-x.x.x-arm64.dmg`（Apple Silicon M 系列芯片）或 `js-pet-x.x.x-x64.dmg`（Intel 芯片），不确定就用 arm64 版（2020 年后的 Mac 基本都是）。
2. 双击 dmg，把 **js-pet** 拖进 **Applications（应用程序）** 文件夹。
3. 在"应用程序"里**右键点击 js-pet → 打开**。
4. 弹窗会提示"无法验证开发者"，点 **打开** 即可。
5. 以后正常双击启动，不会再提示。

## 方法二：系统设置放行（方法一没出现提示时用）

1. 直接双击 js-pet，如果提示"已损坏"或"无法打开"，不要删。
2. 打开 **系统设置 → 隐私与安全性**。
3. 滚动到页面底部，找到"**js-pet 已被阻止**"的提示，点 **仍要打开**。

## 方法三：终端放行（最后手段）

```bash
sudo xattr -rd com.apple.quarantine /Applications/js-pet.app
```

## 常见问题

| 问题 | 说明 |
|---|---|
| 提示"已损坏，移到废纸篓" | 这是 quarantine 属性导致的误报，用方法三即可解决 |
| 提示"无法验证开发者" | 正常，走方法一/二 |
| 数据在哪 | `~/Library/Application Support/js-pet/`，卸载应用不会删除数据 |
| 能联网吗 | 不能，也不需要。js-pet 不发起任何网络请求 |

## 为什么不签名？

代码签名证书需要 Apple Developer Program 会员（$99/年）。js-pet 是免费软件，
v1 阶段选择不签名以降低成本，代价就是需要你手动放行一次。后续版本如果用户量大，
会考虑接入签名。
